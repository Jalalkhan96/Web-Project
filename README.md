# Web Project

Early HTML/CSS/JavaScript practice pages from my first web development work (2024) — login forms, a file card, a video player, a link tree, and form/tag practice pages. Each folder is a small standalone page.

## What it is

A collection of independent beginner web exercises. There is no build step and no shared code: every folder below is a self-contained mini-page (HTML + CSS, some with a little JavaScript) built while learning a specific concept — page layout, forms, CSS borders and grids, DOM events, promises, and so on.

## Contents

```
Boader/             Border/layout practice page (index.html + stlye.css)
File Card/          Profile file-card page (index_file_card.html)
Form/               Bare form page skeleton
Javascript Here/    JavaScript topic exercises, one folder per topic:
                    Introduction, Data Type, Operators, Conditional Statement,
                    Switch Case, Loops, Function Here, Arrays Here, Array Call Back,
                    Call Back, Promises, Set Time Out, DOM EVENT, DOM Manipulation
Login/              "Abix Login" — popup login form page with nav header (HTML/CSS/JS)
Login_1/            Second login page variant (HTML/CSS/JS)
My Own Link Tree/   Personal link-tree page (profile photo, link list, Media.txt)
My own Practice/    General HTML/CSS/JS practice page
Picture/            Picture display page
Practice Tasim/     CSS practice set: Animation, Box_Pract, CSS_GRID, Demo Web Site,
                    Images_Text, NetFlix_Copy, Paragraph, Resume, Scale In Css,
                    Sign_Up_Page, TASIM_BRO, Tasim Pseudo, Transition CSS,
                    Var WDP, Web site CSS, nav_bar, images
Tags/               HTML tags reference page (with rr.txt notes)
Video_Player/       HTML5 <video> element practice page
```

## Run it

No install or server needed — open any folder's HTML file in a browser:

```bash
# examples
open "Login/index.html"
open "Video_Player/index.html"
open "My Own Link Tree/index.html"
```

Some pages reference local images/videos that live in the same folder, so open the file from inside its folder rather than copying it out alone.

## Tech

- HTML5, CSS3, vanilla JavaScript — no frameworks, no build tooling
